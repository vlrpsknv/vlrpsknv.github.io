  14. 14 · Trading Screener

    From a table to the map

    How the Depth Map was found: the same orders in five layouts. Step through them.

    Trading Screener case

    Digash · design process

    From a raw table to the Depth Map

    Raw order table

    The starting point: every large order as a row of numbers. Beginners did not understand the raw order book, and pros still needed its precision.

    3 × 3 grid

    A layout the team suggested: a grid by proximity and size. I tested and rejected it. It wasted space and overlapped clusters.

    Wave

    The team’s other idea, a wave-style shape. Tested and rejected for the same reasons: wasted space and overlapping clusters.

    Scatter plot

    My first prototype: X is distance from price, Y is volume. It collapsed in the center, but it sparked the core idea: use distance as a visual anchor.

    Depth Map

    A radial format inspired by radar UIs. Radius is % distance from price, size is volume, color is buy or sell. New users got it, pros found precision.
