The problem

Creators of AI series build every episode across several tools. The script lives in Claude or GPT, the frames in Nano Banana, the video in Seedance or Kling. For every scene they describe the characters again, carry prompts over by hand and keep track of each model’s limits on references, length and format.

One studio for the whole series

Klyp turns that into one pipeline: premise, script, cast, scenes, video. One chat works with 42 models across text, image, video and audio.

Story Mode treats a series as a structure: episodes, a screenplay with versions, scenes, and a cast and locations that carry their reference sheets into every generation.

A writers’ room made of roles

Six roles from a film crew sit on top of the text models: Showrunner, Screenwriter, Director, Editor, Actor and Casting. They work in the chat and inside Story Mode.

The Director writes video prompts one scene at a time and reads a summary of the previous scene first, so the story holds together from clip to clip.

Characters stay recognizable

A character’s reference sheet registers the face once, and every clip uses that asset. The tail of each clip becomes the reference for the next one, so light, positions and props carry over from scene to scene.

After every model response, code checks the prompt before any money is spent: dialogue kept word for word, clip length in whole seconds within the model’s range, no words the video model handles badly.

Design system in code

I built the UI kit: 90 components and 16 templates on 577 design tokens, with a catalog inside the app and a live playground for every component.

Tokens go to Figma as 447 variables and 43 styles, so the design file follows the code instead of the other way round.

Shipping

I wrote the React app and the Convex backend: 139 routes, 55 tables, about 700 functions and durable workflows behind every generation.

My code reaches the product team through an export pipeline I built, which checks every delivery before it leaves.
