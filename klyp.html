One studio for the whole series

Creators of AI series build every episode across several tools. The script lives in Claude or GPT, the frames in Nano Banana, the video in Seedance or Kling, and every scene starts with describing the characters again.

I designed Klyp as one pipeline: premise, script, cast, scenes, video. One chat and one canvas work with 42 models for text, image, video and audio. The two pieces below are sections of the landing I designed and coded.

Story Mode: one line in, a series out

Story Mode keeps a series as data: episodes, a screenplay with versions, scenes, and a cast whose reference sheets go into every generation.

I designed and coded its landing. It opens with a poster you build yourself.

Six skills, one film crew

The chat has six skills, each a film-crew role: Showrunner, Screenwriter, Director, Editor, Actor and Casting. They also work inside Story Mode.

The Director reads a summary of the previous scene before writing the next one, so the story holds from clip to clip.

Characters stay recognizable

Each character’s face is registered once, and every clip uses that sheet. The last frames of a clip become the reference for the next, so light, positions and props carry over.

Before any money is spent, my code checks every video prompt: the dialogue word for word, and a clip length the model accepts.

Design system and code

I built the UI kit: 90 components and 16 templates on 577 design tokens, with a catalog inside the app and a live playground for every component. Tokens go to Figma as 447 variables and 43 styles, so the design file follows the code.

I wrote the React app and the backend. Every generation runs as a workflow that survives a failed step. The product team gets my code through an export pipeline I built, which stops a delivery when a check fails.
